- 硬约束：AGENTS.md §4（一页一功能、入口出口、奥卡姆剃刀）

| 统一叫法 | 含义 | 不再使用 |

## 3. 每页规格
### P0 自检开屏

- 主动能：自检并自动进入
- 入口：冷启动；失败后点「重试」重跑
- 出口：可互传、仅局域网 → 自动进入（首次进 P1，否则进 P2）；不可用、无权限 → 停留在本页
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 品牌标识 | 冷启动第一帧，确认打开的是对的应用 |
| 循环进度动画 | 唯一表示"还在跑"的信号，缺了像卡死 |
| 一行状态文案 | 说明当前在做什么；失败时说明原因 |
| 重试（仅失败态出现） | 失败后不重启 App 的唯一出路 |

- 状态：

| 状态 | 显示 | 去向 |
| --- | --- | --- |
| 启动中 | 正在启动 | 接着自检 |
| 检测中 | 正在检测网络 | 接着自检 |
| 可互传 | 可互传 | 停留 ≥400ms 后自动进入 |
| 仅局域网 | 仅局域网可用 | 一行警告，约 1s 后自动进入 |
| 不可用 | 网络不可用 | 停留，写明原因，仅「重试」 |
| 无权限 | 本地网络未授权 | 停留，拉起系统授权，授权后自动复检 |

- 文案：`正在启动` `正在检测网络` `可互传` `仅局域网可用` `网络不可用` `本地网络未授权` `重试`

### P1 用户名

- 主动能：设定本机在群内的显示名
- 入口：P0 自检通过后自动进入（首次启动）
- 出口：「保存」→ 无群组进 P5，有群组进 P2
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 用户名输入框（预填设备名） | 主动能本体；入群后他人靠它认人 |
| 保存 | 唯一提交动作，缺则改不了名 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 保存中 |
| 空 | 请输入用户名 |
| 错误 | 保存失败，重试 |
| 离线 | 离线可设，入群后生效 |

- 文案：`用户名` `我的设备` `保存` `请输入用户名` `最多 20 字` `保存中` `保存失败`

### P2 首页

- 主动能：进入某个群组
- 入口：冷启动（已有群组）；任意页系统返回一次
- 出口：点群组行 → P3；右上「设置」→ P7；「+」→ P5
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 群组列表（名称 / 做种数 / 未读） | 主动能载体 |
| 搜索框 | 群多后唯一定位手段 |
| 未读角标（行内） | 不看它就不知道哪个群有新文件或新评论 |
| 设置（右上） | P7 唯一入口 |
| 新群组「+」 | P5 唯一入口 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 正在加载 |
| 空 | 还没有群组 |
| 错误 | 加载失败，重试 |
| 离线 | 离线，仅显示缓存 |

- 文案：`搜索群组` `还没有群组` `做种 3` `{n} 条新消息` `设置`

### P3 群组

- 主动能：打开群内某个文件
- 入口：P2 点群组行
- 出口：点文件行 → P4；顶部「成员」→ P6；系统返回 → P2
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 文件列表（名称 / 大小 / 状态 chip） | 主动能载体，观感对齐资源管理器 |
| 添加文件 | 文件进群的唯一入口，缺它 M1 闭环断链 |
| 成员（n 人） | P6 唯一入口 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 正在加载 |
| 空 | 还没有文件 |
| 错误 | 加载失败，重试 |
| 离线 | 离线，显示缓存 |

- 文案：`添加文件` `做种中` `休眠` `下载中` `组队 {n} 人` `做种 1` `还没有文件`

### P4 文件详情

- 主动能：控制该文件在本机的激活/休眠
- 入口：P3 点文件行；P3「添加文件」完成后直接进入
- 出口：系统返回 → P3
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 文件信息（名称 / 大小 / 来源成员） | 认出这是哪个文件、谁给的 |
| 进度与速度（含组队行） | 唯一能看出在动还是卡住的信号 |
| 激活/休眠开关 | 主动能本体，全 App 只有这一个开关 |
| 「…」溢出菜单（单文件限速、分享链接） | 大文件吃满带宽时只有这里能压；分享链接只能从文件进。两项收进菜单，本页元素仍为 5；没配分享服务时这一项里只剩限速 |
| 评论输入行（含发送） | 唯一反馈渠道；回复靠点评论行带入名字 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 正在连接做种者 |
| 空 | 还没有评论 |
| 错误 | 连不上做种者，重试 |
| 离线 | 离线，等待上线 |

- 文案：`激活` `休眠` `正在组队 · {n} 人` `做种者 1` `等待做种者` `写评论` `发送` `还没有评论` `回复 `

### P5 新群组

- 主动能：成为某个群的成员
- 入口：P2「+」；首次启动时由 P1 直接进入
- 出口：加入或创建成功 → P3；系统返回 → P2（首次启动无返回）
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 邀请码输入框（只收后 8 位） | 加入的唯一凭据 |
| 加入 | 加入的提交动作 |
| 新建群组 | 没群可入时的唯一出路 |
| 建群弹窗（群名 + 创建） | 群名是 P2 列表里的识别符，默认已填可直接过 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 加入中，输入框只读 |
| 空 | 邀请码后 8 位 |
| 错误 | 邀请码不对 / 加入失败 |
| 离线 | 离线，无法加入 |

- 文案：`新群组` `加入` `加入中` `新建群组` `邀请码后 8 位` `邀请码不对` `{用户名}的群组` `创建`

### P6 成员

- 主动能：看清谁在群里、谁在做种
- 入口：P3 顶部「成员（n 人）」
- 出口：系统返回 → P3
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 成员列表（名字 / 在线 / 做种数） | 主动能载体；组队队友就在这一列里 |
| 邀请码（16–20 位，点按复制） | 拉人进群的唯一凭据，只在此处出现 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 正在加载 |
| 空 | 暂无成员 |
| 错误 | 加载失败，重试 |
| 离线 | 离线（成员在线状态是内核实时值，不显示缓存） |

- 文案：`成员` `在线` `离线` `做种 2` `邀请码` `已复制` `暂无成员`

### P7 设置（抽屉）

- 主动能：改全局参数
- 入口：P2 右上「设置」
- 出口：系统返回或下滑 → P2
- 元素：

| 元素 | 为什么必须留 |
| --- | --- |
| 用户名（当前值，可就地改） | 全 App 唯一改显示名的地方 |
| 全局限速（上行 / 下行 / 不限） | 唯一能整体压制带宽的地方 |
| 通知（逐群三档） | 群级提醒只能在这配 |
| 网络状态（只读一行） | 一眼看清当前链路；只读，不再开第二个自检入口 |
| 分享管理（n 条） | P9 唯一入口；没有有效分享、或未配置分享服务时不出现 |

- 状态：

| 状态 | 显示 |
| --- | --- |
| 加载 | 读取中 |
| 空 | 无空态 |
| 错误 | 读取失败，重试 |
| 离线 | 离线可改，联网后生效 |

- 文案：`设置` `用户名` `全局限速` `通知` `网络状态` `系统气泡` `仅应用内` `静音` `分享管理`

### P8 链接分享

- 主动能：把这条链接交出去
- 入口：P4「…」→「分享链接」；系统分享（ACTION_SEND）导入完成后自动进入；P9 点行
- 出口：系统返回 → 进入它的那一页（P4 / P2 / P9）

| 元素 | 为什么必须留 |
| --- | --- |
| 二维码 | 主动能载体；扫码是拿到文件的唯一免输入路径 |
| 分享链接 | 不经扫码的出口，拉起系统分享菜单（Windows 落为复制到剪贴板） |
| 状态行 | 唯一回答"能不能取、还有多久失效、正在发给谁"的位置 |

- 状态：`导入中 1/3` · `可分享` · `7 天后失效` · `正在发送 42%` · `已失效` · `分享服务未配置` 加 `重试`

### P9 分享管理

- 主动能：撤销一条链接
- 入口：P7「分享管理」；出口：系统返回 → P7；点行 → P8

| 元素 | 为什么必须留 |
| --- | --- |
| 分享列表（文件名／创建时间／被访问 n 次） | 主动能载体；一条有效链接一行 |
| 行内「撤销」 | 中断滥用的唯一动作；列表项内部操作，不计元素 |

- 状态：`正在读取` · `还没有分享` · `读取失败，重试` · 离线显示本机记录
- 列表只放仍有效的分享（撤销或过期即移出），所以没有"已撤销／已过期"两态；文案：`分享管理` `被访问 3 次` `撤销` `还没有分享`

## 4. 关键流程
1. 启动：自检（启动中 → 检测中）→ 可互传或仅局域网 → 自动进入 P1 或 P2，全程无点击；不可用仅「重试」
2. 建群：P2「+」→ P5「新建群组」→ 弹窗预填「{用户名}的群组」→「创建」→ P3 → P6 点邀请码复制
3. 邀请加入：A 在 P6 复制 16 位邀请码 → 线下发给 B → B 在 P2「+」→ P5 只输后 8 位 →「加入」→ P2 出现该群 → 点行进 P3
4. 共享文件：P3「添加文件」→ 选文件 → 进 P4（开关默认开）→ 进度到 100% → 状态「做种中」→ 群友 P3 该行显示「做种 1」
5. 发现并下载：群友在 P3 看到新行 → 点行进 P4 → 打开「激活」→ 状态「下载中 42%」→ 100% 后转「做种中」
6. 组队：同群两人都开了同一文件 → P4 进度下方显示「正在组队 · 2 人」→ P3 该行 chip 显示「组队 2 人」→ 双方 100% 后 chip 消失、各自转「做种中」
7. 评论：P4「写评论」→ 输入 →「发送」→ 新行置顶 → 对方 P2 该群未读 +1 → 进入 P4 可见 → 点评论行 → 输入行变「回复 名字」→「发送」
8. 通知配置：P2「设置」→ P7「通知」→ 逐群选「系统气泡」/「仅应用内」/「静音」→ 返回 P7 → 返回 P2
9. 链接分享：P4「…」→「分享链接」→ P8 出二维码 →「分享链接」拉起系统菜单发到 QQ/微信；对方浏览器打开 W1 → 连上自动传 → 保存
10. 系统分享进来：文件管理器选中文件 →「分享」→ 互传 → 前台导入 → 直达 P8（无选群页、无选择页）
11. 撤销：P7「分享管理」→ P9 点「撤销」→ 一次确认 → 该行消失、正在取的访客当场断、链接即刻失效

## 5. 概念数据模型
| 实体 | 关键字段 |
| --- | --- |
| 本机 | 用户名、设备名、全局限速（上/下）、通知默认档 |
| 成员 | 名字、在线、做种数、平台 |
| 群组 | 名称、邀请码（16–20 位）、成员[]、文件[]、通知档（3 值） |
| 文件 | 名称、大小、来源成员、状态、进度、队友数、单文件限速、评论[] |
| 评论 | 作者、正文、时间、父评论（空为顶层） |
| 传输 | 文件、做种者数、上行、下行 |
| 设置项 | 用户名、全局限速、通知档（逐群）、网络状态 |
| 分享链接 | token（26 字符）、文件清单、创建时间、失效时间、状态、被访问次数、本机文件路径 |
### 文件状态机

| 当前 | 条件 | 转到 |
| --- | --- | --- |
| 休眠 | 开关开，本机有完整文件 | 激活 |
| 休眠 | 开关开，本机不完整，群内 ≥1 做种者 | 部分 |
| 休眠 | 开关开，本机不完整，无做种者 | 休眠（不变） |
| 部分 | 下载完成 | 激活 |
| 部分 | 开关关，或做种者全部离线 | 休眠 |
| 部分 | 第二个成员与本机互连且同处于该文件「部分」 | 部分（队友数 +1） |
| 激活 | 开关关 | 休眠 |
| 激活 | 本机文件被移走或删除 | 休眠 |
| 任意 | 群内该文件记录被删 | 条目移除 |

- 组队：仅存在于「部分」；队友数 = 当前实际与本机互连、且同处于该文件「部分」的成员数（观测值，以 BT 连接实况计，不按成员表或协议帧推算；做种者不计入）；界面「N 人」= 队友数 + 1（含本机）；文件到 100% 即退出组队。

## 6. 极简裁决表
| 删掉 | 原出处 | 为什么删 |
| --- | --- | --- |
| P0 检测项列表（NAT / IPv6 / IPv4） | 本稿前版 | 自检不需要用户参与，看不懂的数只增加停留时间 |
| P0「进入」按钮 | 本稿前版 | 机器能判的事不让用户点，达标即自动进 |
| P0「重测」按钮 | 本稿前版 | 与失败态「重试」同义，两个按钮一个动作 |
| 首页的第二功能 | — | 搜索、未读、设置、＋ 是导航控件；删任一都会让 P5 或 P7 失去唯一入口 |
| 共享单独开页 | — | 文件进群只在 P3 内完成，不为它新增独立页 |
| 底栏三 Tab（记录/连接/设置） | 旧原型 | 一页一功能；群列表 + 设置抽屉已覆盖，三 Tab 把设置抬成并列目的地 |
| 群内 动态/文件/成员 三页签 | 旧原型 | 群的主物件只有文件；成员降为顶部一个入口 |
| 群动态 / 群文字聊天 | 旧原型 | 老板未提；评论挂在文件上已够协作信息 |
| 1:1 配对、二维码、SAS 校验 | 旧原型 | 邀请制已解决"连上人"，配对是第二条并行入口 |
| ~~分享链接~~、取件码、二维码 | 旧原型 | **已推翻**：L0 2026-11-06 要求链接分享（P8/P9，M2）；取件码与 8 位短编号仍删，理由见 link-share.md §7 |
| 注册 / 登录 / 账号 | — | 只有用户名，本地保存 |
| 「传输中」独立分区 | 旧原型 | 进度归文件详情 P4，首页只做导航 |
| 文件筛选 chips / 排序菜单 | 旧原型 | M1 群内文件少；搜索只放群组层（P2） |
| 设置里的单文件限速 | 老板原话 | §4.1 一功能一入口：就近放 P4，设置只留全局限速 |
| 二次确认 / 帮助页 / 新手引导 / 空态插画 | — | §4.3：除删群、删文件外不做确认，也不做任何教学内容 |
| 主题切换 / 关于页 / 版本号页 | 旧原型 | 主题跟随系统；关于页无可执行动作 |
